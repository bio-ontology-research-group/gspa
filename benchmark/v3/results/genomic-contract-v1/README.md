# Genomic TSV and native geNomad contract repair

Thirteen JVM regressions and fifteen Python subcases fail before repair. The
repaired gate passes 1,384 JVM tests (six optional skips), six Python methods,
33 focused checks and sixteen production CLI/native-process fixture replays.
The first replay's incorrect expectation about lowercase inf is retained.
Independent checks rehash 240 CLI files and verify saved outcomes, source bytes
and complete test reports. Upstream source/commit records and tested overlays
are preserved. Large engines/runtime packages remain hash-bound on Unimatrix.

Controlled native-process fixtures do not establish real tool execution or
biological accuracy. No whole audit requirement is accepted.
