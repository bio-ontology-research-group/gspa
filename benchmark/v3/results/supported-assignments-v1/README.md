# Supported assignment construction: mechanism evidence

The production guided route constructs independently supported complex AND clauses
and joint multifunction hypotheses, preserving alternative reaction mappings and
the null. Explicit groups and partner evidence are required; no target GPR is read
to supply partners or activities. This is a synthetic mechanism verification, not
biological function recovery or planner superiority.

`supported-cli/` contains five actual CLI arms: single-medium, fixed, random,
evidence-guided and changed-hidden-assignment. Independent COBRApy/GLPK agrees on
all 200 control/knockout phenotype and checked flux-interval comparisons. The full
arms visit six conditions with 86 solver calls; single-medium uses 16. Every arm
has the same 256-call cap and public hypotheses/menu. Changed hidden target GPRs
preserve every result cell. `simple-cli/` replays the previous five-arm fixture on
this engine and agrees on all 54 independent comparisons. Neither suite promotes
functions or produces calibrated probabilities.

`first-oracle-failure/` preserves the first run, which stopped at random-arm
46/48 agreement. A null hypothesis's knockout of an unused model gene persisted
across COBRA contexts and contaminated later complex hypotheses. Isolated replay
of both disputed cells agreed with production before the checker fix (see
`tests/supported-oracle-isolated.json`). The oracle now copies the model for every
simulation. Two failing-before isolation/order tests and three passing-after
tests preserve the evidence. The failure archive has no completion receipt.

Two other failing-before real LP tests reproduce separate evaluation of knockout
records and condition-versus-target knockouts, which could leave OR isozymes
active. The production solver now evaluates the cumulative gene set. All 20
masked-assignment and 53 existing metabolic tests pass.

Sixteen new JVM cases cover construction and input/role/group/cap semantics.
Before implementation, five cases in the initial 24-case suite failed; the final
28-case suite passes. Full JVM validation: 1,026 tests, no failures/errors, two
skips. Full final benchmark validation: 528 tests, no failures, 11 opt-in/optional
skips; all eight Nextflow opt-in cases pass separately with the exact engine.
The earlier 525-test benchmark run also executed all eight live Nextflow cases.

`code/` freezes relevant sources and tests; `before/` preserves pre-fix solver and
oracle versions. Commands, complete results, private construction reports, stage
ledgers, fixtures and execution-time hashes are retained. Model/input/source
hashes from both successful replays were verified again during archival. The JAR
is retained at the content-addressed path in `engine.json`, not duplicated here.
`sha256.json` binds every other archive file and is independently checked after
writing. No whole audit item is accepted by these checks.

Reproduction and remaining requirements are documented in
`docs/benchmarks/v3-masked-assignment-experiments.md` and `tasks/v3-acceptance.md`.
