# Family-excluded report verifier addendum

The old verifier accepted NaN and an inconsistent supported score status. Failing
regressions, the repair and passing tests are preserved. An independent scan of
all 544,732 exact archived candidate/model outputs confirms finite probabilities
and valid statuses without changing production outputs. The original complete
outputs remain in [the prior archive](../family-excluded-training-v1/README.md).
This addendum binds that archive index and production verification receipt.

See [the report](../../../../docs/benchmarks/v3-family-excluded-training.md).
`index.json` maps original files to content-addressed gzip objects; decompressed
hashes are verified. `SHA256SUMS` covers all files except itself.
