# Phase 5 — master dark-matter shortlist

Generated by `build_shortlist.py` from the Phase 4 per-genome
augmented predictions over the 97-genome KAUST panel.

## Filter

A row is emitted only if **all** of the following hold:

- **Top-3 candidate** for its gap reaction in its own genome
  (reaction-local context kernel density rank, from
  `predict_dark_matter.py`).
- **Cross-genome log_lr ≥ 0.3** — the candidate's orthogroup (50% id /
  80% cov MMseqs cluster over 387K panel proteins) is enriched at
  least 2× in R-signature windows across the panel relative to its
  baseline prevalence.
- **Dark by BLAST**: max DIAMOND pident < 30% against Swiss-Prot.

## Deduplication

Same (culture, candidate, gap_rxn, gap_ec) can appear multiple times
because a single gap reaction may resolve to multiple SEED equivalents
through the EC alias table; we keep the row with the highest log_lr.

## Columns

| Column           | Meaning                                           |
|------------------|---------------------------------------------------|
| `culture`        | Panel genome tag                                  |
| `phylum`         | From GTDB-Tk class-level placement                |
| `candidate`      | Protein ID (contig_N from prodigal FAA)           |
| `rank`           | 1-3 density rank within the gap                   |
| `log_lr`         | log10 ratio of signature-window prevalence / baseline prevalence for the candidate's orthogroup |
| `n_hits`         | How many SEED equivalents of the gap reaction had catalog entries above the 0.3 cutoff |
| `orthogroup`     | MMseqs-50% cluster rep protein ID                 |
| `gap_rxn`        | gapsmith bad_blast/no_blast reaction ID           |
| `reaction_name`  | From gapsmith Reactions.tbl (culture-specific) or seed_reactions.tsv |
| `gap_ec`         | EC number of the gap                              |
| `ec_name`        | From ec2go                                         |
| `density`        | Reaction-local context density at the candidate's genome position |
| `n_anchors`      | Number of neighbor-reaction anchors informing the density |
| `max_pident`     | Max pident from DIAMOND blastp vs Swiss-Prot      |
| `gene_context`   | Nearest annotated neighbors on the contig         |

## Files

- `shortlist_master.tsv` — all rows, sorted log_lr desc
- `shortlist_<Phylum>.tsv` — per-phylum subset (Pseudomonadota,
  Bacillota, Actinomycetota, Bacteroidota)

## Interpretation

A row like

    enrichment__C-23_07_C-23_metaflye.4 | Actinomycetota |
    contig_32_323 | log_lr=1.646 pident=0.0 EC=3.6.1.11
    exopolyphosphatase

reads as: *in C-23 Actinomycete MAG bin 4, the protein contig_32_323
has no recognizable Swiss-Prot homolog at 30% identity, sits in the
genomic neighborhood of reactions that are upstream/downstream of
exopolyphosphatase, AND its orthogroup (the 50%-id cluster it belongs
to across the panel) shows up in the exopolyphosphatase R-signature
context ~44× more often than you'd expect from its baseline panel
presence*. That makes it a high-value experimental target: the gap is
biologically plausible, the local evidence is consistent, and the
cross-genome pattern converges.

## Next

Phase 6 validates the shortlist via two orthogonal tests:

1. **Convergent evidence** — does the same orthogroup appear as a
   candidate for the same reaction across multiple independent
   phyla?
2. **Signal decay** — rebuild the catalog at panel sizes 29 / 60 / 97
   and check that log_lr stabilizes rather than simply inflates with
   panel size.
