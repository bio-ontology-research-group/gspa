# dbCAN overview formatter contract

These files were generated by executing the unmodified overview-writing block of
upstream `run_dbCAN`, commit `fb8a1fdfb47199c97355ba5938d3ce6a3bab2686`, against
controlled synthetic HMMER, dbCAN-sub and DIAMOND component hits. They are actual
formatter outputs, **not a complete dbCAN run or biological predictions**.

The source is
https://github.com/linnabrown/run_dbcan/blob/fb8a1fdfb47199c97355ba5938d3ce6a3bab2686/dbcan/cli/run_dbcan.py.
`formatter-extraction.json` identifies the source hash and executed line range.
Both default and optional SignalP layouts are preserved. Component inputs and
the reproduction recipe belong to the dbCAN contract benchmark archive.
